# Sportify
Spotify is a static sports activity app, developed with the goal of recording favorite workouts, workout locations, reminders, and offering a unique feature among sports apps. It boasts high fidelity in a functional and responsive interface..

## Technologies
This project was built using the modern hybrid development ecosystem:

Framework: Ionic + Angular

Languages: HTML5, SCSS, TypeScript

Data: JSON for simulating static content

Design: Faithfully based on a Figma prototype

## Required
Before you begin, you will need to have the following installed on your machine:

Node.js (LTS version recommended)

Package manager (NPM comes with Node)

## Installation and Execution
### Install the Ionic CLI globally:
```bash
npm install -g @ionic/cli
```
## Clone the repository
git clone https://github.com/leeonealves/sportify.git
cd wash-up-app

## Install the project dependencies
```bash
npm install
```

## Run the Application
```bash
ionic serve
```
